# Startup logo sources

- Startup India: https://www.startupindia.gov.in/content/dam/invest-india/newhomepage/Logo1.png — original indexed PNG with transparency, downloaded 2026-11-14.
- Startup Karnataka: https://www.startupindia.gov.in/content/dam/invest-india/Templates/public/state_startup_policies/Karnataka_Startup_Policy.pdf — official policy cover symbol. Original vector polygons and colors extracted with no background; this is the standalone symbol, not a recreated wordmark.

These are program logo marks, not scans of company-issued recognition certificates. No registration number or recognition date is inferred from these assets.
